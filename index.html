How to read this plan

Time starts at zero. Dependencies are finish-to-start with no lag. Durations are whole time units; zero-duration milestones are supported. Resources are unlimited, so independent tasks can overlap. Weekends, calendars, uncertain durations, and staff limits are not modeled.

Total float is how far a task can move before the overall finish moves, with other durations fixed. Free float is how far it can move without delaying the earliest start of an immediate successor. A critical task has zero total float. The latest schedule uses the earliest possible project finish as its deadline.

The app rejects cycles with a closed dependency witness. It counts all longest source-to-sink routes, including distinct zero-duration milestone routes. The displayed route is one example, not the only route.

Files contain a single tasks array. Each task has id, label, duration, and depends. Up to 64 tasks; duration 0–10,000. Everything stays in your browser. Save before refreshing.
